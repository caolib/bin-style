# Compact Status

```
/plugin install compact-status --marketplace caolib/bin-style
```

在 Claude Code 输入框上方显示单行彩色状态信息，使用 Powerline 半圆分隔，不修改原有底部状态栏、消息边框或 `/ustyle` 面板。

```text
模型(思考程度)  已用比例 / 总窗口  当前上下文 (上次缓存命中率)  仓库目录  分支 ↑领先↓落后 (+新增,-删除)
```

## 显示与颜色

五段分别使用蓝、绿、黄、红与深灰背景（主题决定具体色值），前四段为深色文字、Git 段为浅色文字；Git 的 `+新增` 为翠绿，`-删除` 为朱红。缓存命中率只在 `plain` 主题里着色（≥ 90% 绿、低于 90% 红、未知用中性色）；有背景的主题里它跟随本段文字色。各段之间用 Powerline 半圆连接：整条以半圆开头，段间用半圆（下一段颜色叠在上一段背景上，使每段以圆弧起始），结尾为半圆（U+E0B6、U+E0B4），需要 Nerd Font 字体才能正确显示。不显示 TPS。默认文字与背景的 WCAG 对比度均大于 4.5:1。

最快的方式是 `/config` 里的 **配色主题**：`default`、`onedark`、`tokyo-night`、`gruvbox`、`nord`、`catppuccin`、`mono`、`plain`，选中即整套切换。`plain` 不画任何背景，只用前景色区分各段，段间是暗色圆点 `·`；上下文段与 Git 段用同一中性文字色，只有其中的命中率保持绿/红。

想先看效果，运行 `/status-theme` 打开预览面板：每个主题一行完整的状态栏样例（含 `+123`/`-456` 与命中率），确认后再去 `/config` 选择。`/config` 的选择器由引擎绘制，无法在选择过程中内嵌预览，所以预览放在这个面板里。

配色只由主题决定，不再单独提供各段颜色选项。

信息栏高度固定一行，插件内外边距均为零。窄窗口末尾省略，不换行撑高。Claude Code 输入框外层自身的上边距不属于此信息栏，Mod 无法通过内部布局改变它。

## 统计口径

- 模型使用会话当前模型，显示时只保留 `/` 后最后一段，例如 `provider/group/model` 显示 `model`，不改变实际调用的模型。
- 思考程度优先采用实际主会话请求的 effort，首个请求前读取 `CLAUDE_EFFORT` 或 `effortLevel`。
- 上下文与窗口来自宿主 `session.usage()`。`922.0k` 这样的数字表示总窗口，不是剩余容量。
- 当前上下文包含普通输入、缓存写入与缓存读取 token，不包含输出。
- 上次缓存命中率 = 缓存读取 token /（普通输入 + 缓存写入 + 缓存读取 token）。不同于 ccstatusline 的 `cache-read` 组件，新栏数量显示完整输入上下文，而非仅缓存读取量。
- Git 目录为当前工作树根目录的末段。`+/-` 为未暂存与已暂存变更的新增/删除行数之和；未跟踪文件与二进制内容不计入行数。分离 HEAD 显示短提交 ID；无法读取时显示 `—`。
- `↑/↓` 为相对上游分支的领先/落后提交数，只显示非零的一侧；没有上游时省略。
- 不显示或统计 TPS。

## 行为与权限

Git 每五秒刷新一次；相同数据不触发重绘，进程不会重叠运行。Git 使用只读命令并禁用 external diff、textconv 和可选锁，不执行项目脚本。当前窗口数据随宿主测量更新；首次初始化仅使用本地估算的 summary 来取得上次实际缓存统计，不调用 token-count API。

引擎调查问卷占用栏位时主动让出。`/clear` 清除上次缓存指标；模块热重载保留会话状态。旧版 TPS 状态字段会在下次主会话请求返回时移除。

模块仅观察请求，原样传递流式输出，不改变模型、提示词、消息、工具结果、系统设置或已有状态栏。启用需要用户在当前会话的 Mods 提示中确认。源码保存在本会话的 dev-mods 目录，未发布至插件市场。
